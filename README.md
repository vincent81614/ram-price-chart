# 桌上型記憶體價格走勢

以原價屋（coolpc）線上估價單在 Wayback Machine 的歷史存檔為資料來源，重建 DDR3／DDR4／DDR5
桌上型記憶體近一年在台灣的掛牌價走勢。

**線上版：<https://vincent81614.github.io/ram-price-chart/>**

| 檔案 | 內容 |
|---|---|
| `index.html` | 完整獨立網頁，資料已內嵌，無外部相依，雙擊即可開啟 |
| `prices.json` | 世代層級：每個取樣日的每 GB 最低／中位／最高單價、在架款數、限組裝比例 |
| `skus.json` | 逐款資料：14 個容量分組、596 個品項、品牌、每個取樣日的價格 |

## 資料範圍

- 2025-08-03 ～ 2026-07-31，共 **92 個取樣日**，取自 113 份去重快照加 1 次當日線上擷取。
- 全期 **30,203 筆**掛牌報價。
- 取樣點是存檔日期，**非每日連續**，各月密度 3～24 次不等。
- 起點是 2025-08-03，因為 Wayback 在 7/25～8/3 之間沒有存檔。

## 為什麼主圖是「每 GB 單價」

同一個 DDR5 分類裡，8GB 單條和 256GB 套組都在裡面。把它們的標價平均起來，量到的是
「今天剛好上架哪些容量」，不是記憶體的行情。除以總容量之後，三個世代才能放在同一張圖上比。

下方各容量的圖表則是實際標價——因為在「DDR5 32GB」這一組裡面，每一款買到的東西是一樣的。

## 分類方式

- **世代與桌機／筆電之分靠頁面本身的分組**（`<OPTGROUP LABEL='桌上型記憶體 DDR5 雙通道'>`），
  不靠商品名稱。所以筆記型記憶體、伺服器 ECC／RDIMM、NAS 專用模組、以及標籤裡同樣寫著
  「DDR5」的主機板，全部乾淨排除。
- **容量優先讀套組規格**（`32GB(雙通16GB*2)` → 32GB）。有些芝奇的品項**完全不寫總容量**，
  只能從料號尾巴的 `24GX2` 推回 48GB；直接讀第一個數字會少算一半。
  單條品項才退回讀開頭的數字。全期 30,203 筆只有 1 筆解析不出容量（那筆是漏進來的區段標題）。
- 折扣價 `$619↗$650` 取後者。原價屋用 ↗ 標漲價、↘ 標降價，兩種情況現價都是後面那個。

## 品項識別：原價屋一直在改商品名

同一款記憶體，原價屋會不定期在名稱後面加減字樣。例如同一條 UMAX 8GB：

```
UMAX 單條8GB DDR5-4800/CL40 支援 XMP          2025-08 ~ 2025-12
UMAX 單條8GB DDR5-4800/CL40 支援 XMP ~限組裝
UMAX 單條8GB DDR5-4800/CL40 支援 XMP限組裝
UMAX 單條8GB DDR5-4800/CL40 限組裝
UMAX 單條8GB DDR5-4800/CL40                  2026-01 ~ 2026-05
```

這五種寫法是同一個商品。**2025-12-25 那天原價屋把「支援XMP」從商品名整批拿掉**，一次影響
46 組品項。若用完整字串當識別，這些商品的線會在該日集體斷掉又重生，看起來像大量下架。

因此識別時剝除所有**與商品本身無關的字樣**：購買條件（限組裝／組裝價／裝機價…）、
行銷標籤（【AI雙模】【雙參數】）、規格檔名稱（支援XMP／XMP／EXPO）、
促銷倒數（▼下殺到 9/5 10:00）、庫存註記（少量／熱賣／限量）。
剝除後 1,314 個字串收斂為 **641 款**。

（XMP 與 EXPO 可以放心剝除：全資料集裡沒有任何兩款是只差這個標示的，
不同設定檔的版本料號本來就不同。）

### 中段漂移：不能只靠剝字

有些字樣出現在名稱中間，而且**有些是真規格、有些不是**：

```
UMAX 8GB DDR4-2400(1024*8)              ← 同一款
UMAX 8GB DDR4-2400(1024*8)CL17          ←

威剛32GB(雙通16GB*2) DDR5-6000 ... /CL30黑   ← 不同款！
威剛32GB(雙通16GB*2) DDR5-6000 ... /CL48黑   ←
```

CL 一律剝掉的話，上面第二組兩款不同時序的記憶體會被併成一條線，等於捏造出
一段不存在的價格史。所以判斷「是不是同一款」不看字串像不像，看證據：

> **原價屋同一份估價單裡，一款商品只會出現一次。**
> 兩個名稱若曾在**同一天**同時出現，就是兩款商品，不管字面多像；
> 從未同日出現、且差異只在那些註記，才是同一款被改名。

`ramlib.resolve_aliases()` 對每一組候選合併都跑這個同日共存檢驗，通過才併。
實際結果：34 群合併（79 → 34 個名稱），57 群被擋下（多數是 CL 值真的不同）。

順帶一提，`(1024*8)` 與 `(2048*8)` 是不同顆粒密度，屬於真的兩款，不會被併。

## 只計入「可成交」掛牌

搭整機才有的價格不計入（佔全部的 **7.9%**）。原價屋寫法有四種：
**限組裝、~組裝價~、裝機價、限搭機**——四種都要認，只認其中一種會把
另外幾種的搭機專用價當成一般價算進去。

某個世代某日若完全沒有可成交掛牌，不會刪掉該日，而是退回掛牌價並畫成**虛線**；
下方各容量圖裡，個別品項只剩搭機價的區段也畫成虛線。

同一款同一天若同時有一般價與搭機價，取**一般價**——不是取最便宜的那筆。
先取最便宜再過濾的話，該商品會因為最便宜那筆被濾掉而整個從當天的統計消失。

記憶體這邊沒有出現售罄、極缺不收網單、需洽門市這些字樣。

## 限制

- 統計的是「該日在架可成交品項的價格分佈」，不是追蹤同一款。**最低價這條線天生會抖**——
  最便宜那款一下架，最低價就跳到次便宜的，看起來像漲價。看趨勢請用中位數。
- 基準線是各分組**在本資料集第一天（2025-08-03）的中位價**，不是官方定價；記憶體沒有 MSRP。
- 只反映原價屋一家通路，不等於全台均價。下單前請以店家實際報價為準。
- 品牌只取最常見的 7 個，其餘併為「其他」。
