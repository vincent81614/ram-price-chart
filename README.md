# 桌上型記憶體價格走勢

以原價屋（coolpc）線上估價單在 Wayback Machine 的歷史存檔為資料來源，重建 DDR3／DDR4／DDR5
桌上型記憶體近一年在台灣的掛牌價走勢。

**線上版：<https://vincent81614.github.io/ram-price-chart/>**

| 檔案 | 內容 |
|---|---|
| `index.html` | 完整獨立網頁，資料已內嵌，無外部相依，雙擊即可開啟 |
| `prices.json` | 世代層級：每個取樣日的每 GB 最低／中位／最高單價、在架款數、限組裝比例 |
| `skus.json` | 逐款資料：14 個容量分組、1,137 個品項、品牌、每個取樣日的價格 |

## 資料範圍

- 2025-08-03 ～ 2026-07-31，共 **92 個取樣日**，取自 113 份去重快照加 1 次當日線上擷取。
- 全期 **30,203 筆**掛牌報價。
- 取樣點是存檔日期，**非每日連續**，各月密度 3～24 次不等。
- 起點是 2025-08-03，因為 Wayback 在 7/25～8/3 之間沒有存檔。

## 為什麼主圖是「每 GB 單價」

同一個 DDR5 分類裡，8GB 單條和 256GB 套組都在裡面。把它們的標價平均起來，量到的是
「今天剛好上架哪些容量」，不是記憶體的行情。除以總容量之後，三個世代才能放在同一張圖上比。

下方各容量的圖表則是實際標價——因為在「DDR5 32GB」這一組裡面，每一款買到的東西是一樣的。

## 分類方式

- **世代與桌機／筆電之分靠頁面本身的分組**（`<OPTGROUP LABEL='桌上型記憶體 DDR5 雙通道'>`），
  不靠商品名稱。所以筆記型記憶體、伺服器 ECC／RDIMM、NAS 專用模組、以及標籤裡同樣寫著
  「DDR5」的主機板，全部乾淨排除。
- **容量優先讀套組規格**（`32GB(雙通16GB*2)` → 32GB）。有些芝奇的品項**完全不寫總容量**，
  只能從料號尾巴的 `24GX2` 推回 48GB；直接讀第一個數字會少算一半。
  單條品項才退回讀開頭的數字。全期 30,203 筆只有 1 筆解析不出容量（那筆是漏進來的區段標題）。
- 折扣價 `$619↗$650` 取後者。原價屋用 ↗ 標漲價、↘ 標降價，兩種情況現價都是後面那個。

## 只計入「可成交」掛牌

標示**限組裝**的掛牌不計入（佔全部的 3.9%）——那是搭整機才有的價格，不能單買。
某個世代某日若完全沒有可成交掛牌，不會刪掉該日，而是退回掛牌價並在圖上畫成**虛線**。

記憶體這邊沒有出現售罄、極缺不收網單、需洽門市這些字樣，所以實際上只有「限組裝」這一條在作用。

## 限制

- 統計的是「該日在架可成交品項的價格分佈」，不是追蹤同一款。**最低價這條線天生會抖**——
  最便宜那款一下架，最低價就跳到次便宜的，看起來像漲價。看趨勢請用中位數。
- 基準線是各分組**在本資料集第一天（2025-08-03）的中位價**，不是官方定價；記憶體沒有 MSRP。
- 只反映原價屋一家通路，不等於全台均價。下單前請以店家實際報價為準。
- 品牌只取最常見的 7 個，其餘併為「其他」。
